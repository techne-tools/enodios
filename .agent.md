## Project Context

This is the **Obsidian Hermes** plugin project, which integrates Hermes Agent functionality into Obsidian.

### Key Files
- `src/main.ts` - Main plugin entry point
- `src/Plugin.ts` - Plugin class implementation
- `src/HermesApiClient.ts` - Hermes Agent API integration (remote mode)
- `src/AcpClient.ts` - Hermes Agent ACP integration (local subprocess mode)
- `manifest.json` - Plugin manifest
- `src/Views/HermesChatView.tsx` - Hermes chat sidebar view
- `src/CitationManager.ts` - Bibliography and citation management
- `src/PDFAnnotationManager.ts` - PDF annotation extraction
- `src/TagManager.ts` - Tag suggestion heuristics
- `src/TemplateManager.ts` - Conversation starter templates
- `src/utils/contextEnhancer.ts` - Enhanced note context generation

### Development Stack
- **Runtime**: Obsidian Plugin API
- **Language**: TypeScript
- **UI**: React 18 (via `createRoot`)
- **Styling**: SCSS
- **Build**: `obsidian-dev-utils` (Webpack/esbuild wrapper)
- **Testing**: Vitest
- **Agent Protocol**: `@agentclientprotocol/sdk` (ACP)
