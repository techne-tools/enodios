## Design Context

### Users
The primary users of Obsidian Hermes are:
1. Researchers and academics focused on citation management, PDF annotations, and note synthesis.
2. Writers, editors, and students seeking prose refactoring, structure editing, and drafting assistance.
The target audience needs to quickly pull context, edit text, synthesize references, and review suggestions without losing their creative or analytical momentum.

### Brand Personality
Obsidian Hermes is **thoughtful, efficient, and unobtrusive**.
*   **Calm Focus**: It exists to augment the user's thinking process, not distract from it.
*   **Technical Fluidity**: It offers immediate productivity gains through seamless autocomplete and fast navigation shortcuts.
*   **Structured Clarity**: The UI presents dense metadata cleanly and collapses complex details by default.

### Aesthetic Direction
*   **Sleek & Minimalist**: Clean layout, generous margins, and minimal visual noise. Hidden tool details by default to keep the focus on the conversation.
*   **Native & Harmonious**: Styles hook deeply into Obsidian's theme CSS variables (`--interactive-accent`, `--text-normal`, `--background-primary`, etc.) to feel like an official core module of Obsidian in both light and dark modes.
*   **Compact & Productive**: Fast transitions, seamless autocompletes, and keyboard-driven command actions.

### Design Principles
1.  **Augment, Don't Disrupt**: The interface should remain visually quiet, collapsing technical logs and reasoning paths by default, so the user's writing remains central.
2.  **Keyboard-First Velocity**: Optimize interaction loops—such as triggers, suggestions, acceptance, and file approvals—so they can be managed entirely from the keyboard.
3.  **Visual Consistency**: Use Obsidian's design tokens and theme color systems so the UI adapts perfectly to any user theme, font scale, or color configuration.
